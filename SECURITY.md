# Security Policy

## Supported versions

| Version     | Supported          |
| ----------- | ------------------ |
| Optixscript10 | Yes (current)    |
| Optixscript   | Best-effort      |

## Reporting a vulnerability

OPTIX is a personal project. Security issues will still be handled, but
please be realistic about expectations:

- Open a regular issue (no need for a special secure channel) describing
  the problem and possible impact.
- Do **not** include private data, account tokens, or secrets in reports.
- If the issue affects the files in `logs/` or any user-specific file
  outside the project, mention that explicitly.
- There is no private reporting channel and no bug bounty. Reports are
  reviewed when the maintainer has time, usually within a few weeks.

## Scope & expectations

This project deliberately runs only PowerShell and Windows built-in
tooling. The Code of Conduct and general "please be kind" spirit
(see README) apply to security reports too.

Thanks for helping make OPTIX safer.
